# Third-party material

Olvin itself is MIT OR Apache-2.0. What follows is shipped inside the repository or baked into built games and is not ours. Licence texts live next to the files and, for games, in the `licenses/` folder that `olvin-hub build` creates.

## Fonts

| Font | Where | Licence | Text |
|---|---|---|---|
| Inter (Regular, Bold; Latin + Cyrillic subset for the built-in text) | `assets/fonts/`, `olvin_text` (built-in font), `olvin_ui` | SIL OFL 1.1 | `assets/fonts/Inter-OFL.txt`, copies in `crates/olvin_text/licenses/`, `crates/olvin_ui/licenses/` |
| JetBrains Mono (Regular, Bold) | `assets/fonts/`, `olvin_ui` (editor and hub UI) | SIL OFL 1.1 | `assets/fonts/JetBrainsMono-OFL.txt`, copy in `crates/olvin_ui/licenses/` |

Games that enable the `gui` feature of `olvin` embed Inter. `olvin-hub build` then writes `licenses/Inter-OFL.txt` and this file into the built folder. A project's own `licenses/` folder is copied there too, so put the notices for your own fonts and assets in it.

## Assets

- `apps/vertical_slice/assets/` (robot model, sounds, music): generated by `apps/vertical_slice/tools/gen_assets.py`, CC0. Not part of the engine or of built games.

## Cargo dependencies

Rust dependencies carry their own licences (mostly MIT / Apache-2.0). Auditing them (`cargo deny` or similar) is not set up yet.
