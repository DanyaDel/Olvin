# Логотип Olvin: что где использовать

<p align="center"><a href="README.en.md">English</a></p>

Описание каждого файла, к какому стилю его привязывать и куда ставить. Правила построения знака (геометрия, цвета, размеры) описаны в [STYLE.md](../../STYLE.md), раздел 9. Здесь практика: что брать в конкретной ситуации.

Галерея всех вариантов на нужных фонах: [variations/index.html](variations/index.html).

## Идея в двух строках

Знак «O▌»: кольцо и зелёный курсор. В вордмарке `Olvin` зелёная буква «l» и есть курсор. Зелёный в логотипе используется только для этого одного элемента.

## Как выбрать файл за три шага

1. **Фон.** Тёмный фон: файлы `on-dark`, `white`, `dark`. Светлый фон: `on-light`, `black`, `light`. Фон неизвестен или цветной: берите плитку (`plate-*`, `circle-*`) или моно.
2. **Размер.** Меньше 24 px: только плоские файлы (`flat`, `plate`, `circle`) и только знак, без слова. От 24 до 64 px: знак. Слово от 120 px по ширине.
3. **Стиль окружения.** Плоский интерфейс и документы: `flat`. Стеклянные панели, заставка, промо на тёмном: `glass`. Декоративные места и водяные знаки: `line`. Один цвет (печать, штамп, терминал): `mono`.

## Стили: к чему какой прикручивать

| Стиль | Что это | Куда подходит | Куда не ставить |
|---|---|---|---|
| **flat** | Белое или тёмное O и зелёный курсор. Основной вариант. | Интерфейс редактора и хаба, документация, README, сайт, всё, что маленькое | — это рабочий вариант по умолчанию |
| **mono** | Один цвет, без зелёного. | Печать в один цвет, штамп, вышивка, гравировка, чёрно-белые документы, фон с цветным баннером, вывод в консоли | Там, где можно показать зелёный: без него теряется узнаваемость |
| **line** | Тонкий контур вместо заливки. | Фон страниц, водяной знак, оформление титульных экранов, обои, большие размеры от 200 px | Меньше 64 px: линии пропадают. Как основной логотип. |
| **glass** | Полупрозрачные формы с бликом и тенью, стиль Liquid Glass. | Заставка редактора, лаунчер хаба, обложки, презентации, промо на тёмном фоне, окно «О программе» | Мелкие значки, светлый фон на тёмном стекле, документы для печати |
| **plate** (плитка) | Знак на закруглённом квадрате. | Иконка приложения, `.exe`, иконки на рабочем столе и в панели задач, карточка проекта | Внутри уже оформленного интерфейса: там плитка будет «карточка в карточке» |
| **circle** (круг) | Знак на круге. | Аватар GitHub и соцсетей, значок канала, иконка в чатах | Иконка приложения: круглые иконки ломают сетку на macOS и Windows |
| **glass-icon / glass-circle** | Плитка или круг с цветным фоном и стеклянным знаком. | Витрина: страница на itch.io, обложка на сайте NLPA, превью в Telegram | Системная иконка: фильтры в SVG могут не поддерживаться |

## Куда что ставить в проекте

| Место | Что взять | Почему |
|---|---|---|
| Окно редактора и хаба, иконка в панели задач | `olvin-icon.svg` (PNG 256/64/32/16, `olvin-icon.ico` для Windows) | Плитка читается при любом размере и совпадает с темой |
| Шапка редактора и хаба | `mark-flat-on-dark.svg` в 24–32 px | В шапке нет места слову. Знак лаконичен |
| Заставка (splash) редактора и хаба | `olvin-mark-animated.svg` + `wordmark-glass-on-dark.svg` или `wordmark-flat-on-dark.svg` | Курсор мигает как в логотипе сайта NLPA. Стекло поддерживает вайб панелей |
| Окно «О программе» | `wordmark-flat-on-dark.svg` и подпись `Olvin · by NLPA Collab` | Слово крупно, без эффектов: окно рабочее |
| Пустой вьюпорт, когда нет проекта | `mark-line-white.svg`, крупно, с низкой непрозрачностью | Декор без шума |
| README в корне репозитория | `wordmark-flat-on-dark.svg` по центру (с тёмным фоном GitHub) и `wordmark-flat-on-light.svg` для светлой темы | GitHub показывает разные темы: используйте `<picture>` с `prefers-color-scheme` |
| Аватар GitHub (социальное превью репозитория `DanyaDel/Olvin`) | `circle-dark.svg` для аватара, `glass-icon-dark.svg` для социального превью | Круглый аватар, тёмный градиент как на сайте |
| Страница Olvin на сайте NLPA | `glass-icon-dark.svg` как обложка проекта, `wordmark-flat-on-dark.svg` в шапке страницы | Сайт в стиле glass на чёрном: вариант попадает в вайб |
| itch.io (страница студии) | `glass-icon-dark.svg` для превью, `circle-dark.svg` для аватара | Витрина любит красивую картинку |
| Telegram-канал и чаты | `circle-dark.svg` или `circle-green.svg` | Круг обрезается чатами по кругу |
| Документация (mdbook, страницы) | `wordmark-flat-on-light.svg` и `wordmark-flat-on-dark.svg` через тему | Документация переключает светлую и тёмную тему |
| Консольный вывод `olvin-hub` | Текстовая версия: `Olvin_` с зелёным подчёркиванием через ANSI | Картинки в терминале не нужны, курсор переносится как текст |
| Установщик, `.exe`, ярлык | `olvin-icon.ico` | Windows берёт иконки только из ICO |
| Презентации, постеры | `glass-icon-*` или `wordmark-glass-*` на тёмном фоне | Максимум эффектности, там размер большой |
| Печать, штампы, вышивка, мерч | `mark-mono-black.svg` или `mark-mono-white.svg` | Один цвет, без градиентов |
| Водяной знак на скриншотах и видео | `mark-mono-white.svg` с прозрачностью 30–50% | Не перебивает кадр |
| Заголовок крупных экранов (тизер, обои) | `mark-line-white.svg` или `wordmark-line-white.svg` | Контур хорош на больших размерах |

## Чего не делать

- Не менять цвета и пропорции вручную. Если нужен новый вариант, добавляйте файл в `variations/`.
- Не растягивать знак по одной оси и не вращать.
- Не ставить знак на пёстрый фон без плитки или моно-варианта. Зелёный курсор на зелёной картинке исчезает.
- Не использовать стеклянные варианты меньше 64 px: блики превращаются в шум.
- Не использовать контурные варианты меньше 64 px.
- Не ставить кольцо с вертикальной чертой внутри: это значок питания.
- Не добавлять второй зелёный элемент рядом с логотипом: зелёный в логотипе только курсор.
- Не показывать знак и слово вместе, если слово уже содержит O: вордмарк сам включает знак.

## Охранное поле и минимальные размеры

- Охранное поле: не меньше толщины кольца (`W`, это 12 единиц из 68 высоты знака, около 18% высоты) со всех сторон.
- Знак: минимум 16 px. Слово: минимум 96 px по ширине.
- Иконки: от 16 px. Стекло и контур: от 64 px.

## Статус подключения

Подключено:

- Иконка окна и панели задач у хаба (`hub/olvin_hub_gui/src/main.rs`) и редактора (`editor/olvin_editor/src/lib.rs`): `png/olvin-icon-256.png` вшита через `include_bytes!` и передана в `ViewportBuilder::with_icon`. Если меняете иконку, перерисуйте PNG из `olvin-icon.svg` (`resvg -w N -h N`), иначе в окне останется старая.
- Консольный логотип `olvin-hub`: `Olvin_` с зелёным подчёркиванием в шапке справки (`olvin-hub --help` и запуск без аргументов). Без цвета при `NO_COLOR` и выводе не в терминал.
- Шапка `README.md` в корне: `<picture>` с `wordmark-flat-on-dark.svg` и `wordmark-flat-on-light.svg`.
- Логотип в интерфейсе рисуется кодом из геометрии `olvin-wordmark.svg`, без растра: `crates/olvin_ui/src/logo.rs` (`wordmark`, `mark`, `wordmark_intro` для заставки). Цвета из темы: кольцо `logo_ring`, курсор `accent` (`#1F9D3A` в светлой). В шапке редактора стоит вордмарк высотой 16 px с мигающим курсором.

Пока не сделано:

- Заставка с анимированным знаком (`olvin-mark-animated.svg`).
- Иконка в `.exe` на Windows (через `build.rs` и ресурсный файл, `olvin-icon.ico`).

При подключении добавляйте запись об этом в `ARCHITECTURE.md`.
