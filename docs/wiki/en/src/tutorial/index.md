# Tutorial: your first game in an hour

A step-by-step tutorial built on the finished game `apps/vertical_slice`: a room with a partition, a first-person character, physics crates, a pressure plate that opens a door, sound, on-screen text, saving with `F5`/`F9`. Each step: what to click in the hub or the editor and which code to write. All code and scenes are taken from the slice (`apps/vertical_slice/`), so you can peek at the original.

## What you need

- Rust, the hub and the editor installed: [Installation](../start/installation.md).
- A GPU with Vulkan, or Mesa (see [installation](../start/installation.md#gpu)).
- Sound files: take `door.wav`, `thud.wav`, `hum.wav`, `theme.wav` from `apps/vertical_slice/assets/` (CC0, generated by `apps/vertical_slice/tools/gen_assets.py`).

## To compare against

```sh
cargo run -p vertical_slice --release    # the finished game
cargo test -p vertical_slice             # 7 tests play the real level without a window
```

> **Status:** Lua scripts do not run in the editor (the Play button does not load them): Lua works in the built game (`olvin-hub run`). There is no `gui` module in the hub catalog, so the feature is added to `Cargo.toml` by hand (step 7).
