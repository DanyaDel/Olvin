# Бенчмарки

`apps/bench` (`olvin-bench`) измеряет, чего стоят горячие пути движка на эталонных сценах, чтобы замедление проявлялось числом, а не ощущением.

```
cargo run --release -p olvin_bench -- [--list] [--only текст] [--json out.json] [--compare benches/baseline.json] [--tolerance 3] [--scale 0.5]
```

Каждый кейс собирает сцену вне замера, делает несколько прогревочных проходов и печатает медиану и лучшее время в миллисекундах. `--only` выбирает кейсы по части имени, `--scale` укорачивает прогоны (не меньше 3), `--json` пишет числа, `--compare` сообщает о каждом кейсе, который медленнее базы больше чем в `--tolerance` раз, и завершается с кодом 1.

| Кейс | Что измеряет |
|---|---|
| `ecs_iterate_100k` | проход 100 000 сущностей запросом |
| `transform_propagation_20k` | мировые матрицы 20 000 объектов в иерархии |
| `physics_pile_500_60_steps` | 60 фиксированных шагов 500 ящиков, упавших на пол |
| `physics_raycast_10k` | 10 000 лучей по 500 ящикам |
| `nav_bake_160k_cells` | запекание уровня 100 × 100 м со стенами |
| `nav_find_path_12_maze` | 12 путей A* по нему (лабиринт: поиск охватывает почти весь уровень) |
| `lod_simplify_100k_triangles` | упрощение меша в 100 000 треугольников до четверти |
| `scene_parse_5000_objects` | разбор файла сцены на 5 000 объектов |
| `save_sign_check_1mb` | подпись и проверка 1 МБ текста сейва |
| `timers_advance_20k` | 20 000 повторяющихся таймеров за 100 кадров |
| `lua_update_5000` | один update 5 000 Lua-поведений |
| `render_prepare_5k_200_lights` | CPU-часть кадра: 5 000 объектов, 200 источников (нужен GPU) |

## В CI

Задача `bench` гоняет набор на раннере GitHub, сравнивает с `benches/baseline.json` и сохраняет числа артефактом `bench-result`. Раннер это не та машина, на которой снята база, поэтому допуск 6 раз: задача ловит замедления на порядок и может падать, не роняя сборку. Для более тонкого прогони набор на одной машине до и после изменения. Базу обновляют через `--json benches/baseline.json` после намеренного изменения, в коммите пишут, на какой машине.

Сам кадр (отрисовка, а не подготовка) измеряется отдельно: `cargo test -p olvin_render perf -- --ignored --nocapture`. Lua против Rust: `cargo bench -p olvin_script --features lua --bench lua_vs_rust`.
