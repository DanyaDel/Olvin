# Языки документации

Политика из STYLE.md, раздел 10.

| Что | Язык |
|---|---|
| Интерфейс редактора и хаба (окна, меню, диалоги, тосты, сообщения CLI) | английский; локализации пока нет |
| Документация (`README`, `ARCHITECTURE`, `STYLE`, `ROADMAP`, `docs/`) | русский основной, английская копия рядом (`*.en.md`) и обновляется вместе с ней |
| Код: идентификаторы, комментарии, doc-комментарии, логи и ошибки | английский |
| Сообщения коммитов | английский, `Область: что сделано (#номер)` |
| Issues и обсуждения | русский |

## Вики

Две книги: `docs/wiki/ru/` (основная) и `docs/wiki/en/` (копия). Имена файлов совпадают, `check_links.py` падает, если страница есть только на одном языке. Переключатель «English / Русский» стоит в верхней панели каждой страницы. Названия элементов интерфейса не переводятся (интерфейс английский): «Window → Add Panel».

Когда появится локализация интерфейса, ключи строк будут на английском, русский станет первой переводной локалью.
