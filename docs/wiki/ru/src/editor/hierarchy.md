# Иерархия

Дерево объектов сцены (панель Hierarchy). Порядок родителей и детей важен: так же упорядочены операции CSG.

## Действия

| Что | Как |
|---|---|
| Выделить | клик; `Ctrl+клик` добавить; `Shift+клик` диапазон |
| Сменить родителя | перетащить строку на другую |
| Переименовать | двойной клик или контекстное меню → Rename |
| Создать | контекстное меню → Create child (те же пункты, что в GameObject) |
| Дублировать / удалить | `Ctrl+D` / `Del` или контекстное меню (выделенные родитель и ребёнок копируются один раз) |
| Порядок | контекстное меню → Move Up / Move Down |
| Отвязать | контекстное меню → Unparent |
| Найти | поле поиска вверху панели |

Из Assets на строку иерархии можно перетащить модель (станет дочерней), материал (назначится) и префаб (станет дочерним экземпляром).

## Префабы

Экземпляры префабов красятся цветом `info` темы со значком ◆ (янтарный ⚠, если префаб не прочитался). Узлы экземпляра нельзя перетаскивать, дублировать и сдвигать по порядку: они остаются там, где их положил префаб. Подробнее: [Префабы в редакторе](prefabs.md).

## Формат

Родители в файле сцены всегда идут раньше детей, иерархия хранится через `parent` (id родителя), см. [Формат сцены](../engine/scene-format.md).

> **Статус:** поиска по сцене, помимо поля в иерархии, нет; multi-scene не сделано, см. [#44](https://github.com/DanyaDel/Olvin/issues/44).
