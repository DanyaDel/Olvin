# Горячие клавиши

Команды редактора и вида сцены (сохранить, создать, отменить, вернуть, дублировать, удалить, играть, настройки, четыре инструмента, Global/Local, кадрировать, Solid/Rendered, ключи) можно переназначить в **Edit → Settings… → Keymap**: нажми на клавишу и нажми новую (`Esc` отменяет); конфликт с другой командой показывается рядом, *Reset* возвращает умолчание, изменения сохраняются для пользователя в `preferences.ron`. Клавиши Edit Mode, UV-редактора, таймлайна анимации и текстовых полей фиксированы. Таблицы ниже это умолчания. На macOS `Ctrl` это `Cmd` в сочетаниях с `Ctrl+S/N/Z/D/P/,`.

## Редактор

| Клавиши | Действие |
|---|---|
| `Ctrl+S` / `Ctrl+N` | сохранить / новая сцена |
| `Ctrl+Z` / `Ctrl+Shift+Z` (`Ctrl+Y`) | отменить / повторить |
| `Ctrl+D` / `Del` | дублировать / удалить выделенное (над Assets: файлы) |
| `Ctrl+P` | Play / Stop |
| `Ctrl+,` | Settings |
| `F2` | переименовать файл в Assets |

## Сцена

| Клавиши | Действие |
|---|---|
| `Q` / `W` / `E` / `R` | Hand / Move / Rotate / Scale |
| `X` | Global / Local |
| `F` | кадрировать выделение |
| `Shift+Z` | Solid / Rendered |
| `Ctrl+клик` | добавить в выделение / убрать |
| `I` / `Alt+I` | ключ Location, Rotation, Scale / удалить ключи на кадре |
| `B` / `T` | CSG: Draw Brush / Resize |

## Edit Mode (`Tab`)

| Клавиши | Действие |
|---|---|
| `Tab` | войти / выйти (примитив или браш конвертируется в `PolyMesh`) |
| `1` / `2` / `3` | вершины / рёбра / грани |
| `A` / `Alt+A` / `Ctrl+I` | выделить всё / снять / инвертировать |
| `G` / `R` / `S` | перенос / поворот / масштаб; `X` `Y` `Z` ось (повтор: локальная), `Shift+ось` плоскость, число, `Ctrl` привязка, `Shift` точность ×0.1 |
| `E` / `I` | экструзия (сразу перенос) / inset |
| `Shift+D` | дублировать |
| `Ctrl+R` / `K` | loop cut / knife |
| `F` / `J` | создать грань / соединить вершины |
| `X` / `M` | удалить / слить |
| `Shift+N` | пересчитать нормали наружу |
| `Alt+клик` / `Ctrl+Alt+клик` | петля / кольцо рёбер (в режиме граней петля граней) |
| `L` / `Shift+L` / `Ctrl+L` | выделить связанное |
| `Ctrl++` / `Ctrl+-` | расширить / сузить выделение |
| `H` / `Shift+H` / `Alt+H` | скрыть / скрыть остальные / показать |
| `Alt+Z` | X-ray |

## UV Editor

| Клавиши | Действие |
|---|---|
| `U` | unwrap |
| `Ctrl+E` | швы |
| `Ctrl+P` | упаковать |
| `G` / `R` / `S` | перенос / поворот / масштаб, `X` / `Y`, числа, `Ctrl` привязка |

## Анимация

Глобальные: `Space` play/pause, `Shift+Ctrl+Space` назад, `Esc` стоп и возврат на старт, `←` `→` кадр, `Shift+←/→` начало/конец, `↑` `↓` следующий/предыдущий ключ. В Dope Sheet и Graph Editor: `A`, `Alt+A`, `B`, `Ctrl+I`, `G`, `S`, `Shift+D`, `X`/`Del`, `Ctrl+C`/`Ctrl+V`, `T` (интерполяция), `V` (тип ручки), `Home`.

## IDE

`Ctrl+Shift+P` палитра, `Ctrl+E` переход к файлу, `Ctrl+G` строка, `Ctrl+/` комментарий, `Ctrl+S` сохранить файл, `Ctrl+W` закрыть вкладку.

## Игра в срезе

`WASD`, мышь, `Space` прыжок, `Shift` бег, `Esc` пауза (`Q` выход на паузе), `F5` / `F9` быстрое сохранение / загрузка.
