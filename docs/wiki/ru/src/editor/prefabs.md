# Префабы в редакторе

Префаб: `*.prefab.ron`, обычная сцена с одним корнем и его детьми. В сцене экземпляр занимает одну запись; формат: [Префабы (движок)](../engine/prefabs.md).

## Как это работает в редакторе

Сцена в памяти хранит экземпляры уже развёрнутыми: каждый узел это обычный объект, поэтому иерархия, вьюпорт и гизмо ничего о префабах не знают. **Правка узла и есть override**. При сохранении сцена схлопывается: в файл идут корень и разница.

## Действия

| Что | Как |
|---|---|
| Создать префаб | GameObject → Create Prefab или контекстное меню Hierarchy: поддерево в `prefabs/<Имя>.prefab.ron`, объект становится экземпляром |
| Поставить экземпляр | перетащить `.prefab.ron` из Assets во вьюпорт или на строку Hierarchy |
| Выделить во вьюпорте | первый клик выделяет весь экземпляр (корень), второй клик по нему же — сам узел |
| Открыть префаб | двойной клик в Assets или Open в инспекторе (откроется как сцена) |
| Откатить | `↺` у поля, Revert All у экземпляра |
| Применить | Apply All: ассет перезаписывается, остальные экземпляры пересобираются |
| Распаковать | Unpack: экземпляр становится обычными объектами |

Блок **Prefab** в инспекторе: Open / Select / Revert All / Apply All / Unpack, список override. У переопределённых полей синий заголовок и подпись с `↺`.

Правка префаба снаружи (в текстовом редакторе) подхватывается: раз в 0,4 с проверяются mtime и размер. Перемещение префаба в Assets переписывает пути; удаление сначала распаковывает экземпляры, объекты остаются.

Ограничения: узлы экземпляра нельзя перетаскивать, дублировать и сдвигать по порядку. Гранулярность override: поле целиком (`position`: весь вектор; `scripts`: весь список).
