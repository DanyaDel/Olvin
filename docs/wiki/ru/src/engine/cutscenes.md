# Катсцены

`olvin_cutscene` (фича `cutscene`, `olvin::cutscene`) проигрывает таймлайн: двигает объекты, переключает камеру, запускает звуки и шлёт сообщения скриптам.

```rust
app.add_plugin(olvin::cutscene::CutscenePlugin);
app.resources.fetch_mut::<Cutscenes>().play_file(&assets, "cutscenes/intro.cutscene.ron");
```

## Файл

`*.cutscene.ron` в `assets/cutscenes/`:

```ron
(
    name: "intro",
    duration: 6.0,
    tracks: [
        (target: "Shot Camera", keys: [
            (time: 0.0, position: Some((0.0, 2.0, 8.0)), ease: Smooth),
            (time: 4.0, position: Some((0.0, 2.0, 3.0)), rotation: Some((-10.0, 0.0, 0.0))),
        ]),
    ],
    cues: [
        (time: 0.0, action: Camera("Shot Camera")),
        (time: 2.0, action: Message(name: "open_door", target: Some("Door"))),
        (time: 3.0, action: Sound(path: "sfx/boom.ogg", volume: 1.0)),
    ],
)
```

- **Дорожки (`tracks`)** двигают объект с именем `target` (ищется по `Name`). Ключ задаёт любые из `position`, `rotation` (углы Эйлера в градусах, как в сцене) и `scale`; каждый канал плавно идёт между ключами, которые его задают, до первого держит первый, после последнего держит последний. `ease`: `Linear`, `Smooth` (плавный старт и финиш) или `Step` для отрезка, который начинается с этого ключа. Каналы, которые ни один ключ не задаёт, не трогаются.
- **Метки (`cues`)** срабатывают один раз в своё время: `Camera(name)` рисует камеру этого объекта (пустое имя возвращает вид), `Message { name, value, target }` шлёт сообщение скриптам (объекту `target` или всем), `Sound { path, volume }` играет звук (нужна фича `audio`).
- Объект, которого нет, пропускается с записью в лог, остальное играет.

Файл проверяется при загрузке: конечные числа, времена от 0, длительность до часа, до 256 дорожек, 20 000 ключей и 4096 меток, имена до 256 байт и пути к звукам внутри папки ассетов.

## Запуск

Ресурс `Cutscenes` запускает `play`, `play_looping` или `play_file` и возвращает id для `pause`, `set_speed`, `skip` (прыжок в конец: объекты занимают конечные места, оставшиеся метки сообщений и камеры срабатывают, звуки нет) и `stop` (всё остаётся как есть). `is_busy()` говорит, идёт ли что-то, чтобы игра могла придержать игрока. Одновременно не больше 16.

Метка камеры ставит маркер `ActiveCamera` на камеру кадра; рендер рисует камеру с ним, иначе первую. Когда катсцена кончается, маркер снимается и возвращается камера игры.

Когда катсцена закончилась (дошла до конца, `skip` или `stop`), приходит событие `CutsceneFinished { id, name, cut_short }`, а каждый скрипт получает сообщение `cutscene_finished` с именем.

## Из скриптов

Отдельных функций нет: скрипты говорят с проигрывателем сообщениями.

```lua
ctx:send("cutscene:play", "cutscenes/intro.cutscene.ron")
ctx:send("cutscene:skip")      -- все идущие
ctx:send("cutscene:stop")
-- on_message(self, ctx, name, value): name == "cutscene_finished"
```

Пока нет: панели таймлайна в редакторе (файлы пишутся руками), путей по сплайнам и поворота кватернионом (углы Эйлера смешиваются по каналам), анимации свойств материалов и света.
