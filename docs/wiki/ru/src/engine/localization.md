# Локализация

`olvin_locale` (фича `locale`, `olvin::locale`) убирает тексты игры из кода: по таблице на язык, поиск по ключу.

```rust
app.add_plugin(olvin::locale::LocalePlugin::new());   // assets/locales/*.ron
let locale = app.resources.fetch::<olvin::locale::Locale>();
let title = locale.tr("menu.play");
```

## Таблицы

Один RON-словарь на язык в `assets/locales/`, имя файла это язык (`en.ron`, `ru.ron`, `pt-BR.ron`):

```ron
{
    "menu.play": "Играть",
    "hello": "Привет, {name}!",
    "coins.one": "{n} монета",
    "coins.few": "{n} монеты",
    "coins.many": "{n} монет",
    "coins.other": "{n} монеты",
}
```

## Поиск

`tr(key)` ищет в текущем языке, затем в **резервном** (по умолчанию `en`), затем возвращает сам ключ: пропущенная строка видна на экране и один раз попадает в лог. `tr_with("hello", &[("name", &"Даня")])` подставляет `{name}`; литеральные скобки пишутся `{{` и `}}`.

## Множественное число

`plural("coins", 5, &[])` выбирает `coins.one` / `coins.few` / `coins.many` / `coins.other` по правилам текущего языка и подставляет `{n}`. Встроены: английский и ему подобные (one, other), русский, украинский, белорусский (one, few, many), польский, чешский и словацкий, французский и португальский (0 и 1 в единственном числе), языки с одной формой (японский, китайский, корейский и другие). Нет нужной формы: берётся `.other`.

## Выбор языка

`LocalePlugin` берёт `OLVIN_LANG`, затем `LC_ALL`, `LC_MESSAGES`, `LANG` (`ru_RU.UTF-8` выбирает `ru`; региональный тег без своей таблицы использует базовый язык). Чтобы язык выбирал игрок: `.language("ru")` у плагина или `locale.set_language("ru")` во время игры (если такой таблицы нет, вернёт `false` и язык не изменится). `locale.languages()` показывает загруженные.

## Для переводчиков

`locale.missing_in("ru")` перечисляет ключи, которые есть в резервном языке и которых нет в `ru`.
