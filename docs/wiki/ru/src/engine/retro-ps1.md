# Ретро-стиль PS1

Вид PlayStation 1 в 3D-рендере: дрожащие вершины, «плывущие» текстуры, 15-битный цвет с дизерингом, освещение по вершинам, жёсткие туман и дальность прорисовки, текстуры nearest, по желанию низкое разрешение. Почему сделано так: [ADR 0003](https://github.com/DanyaDel/Olvin/blob/main/docs/adr/0003-retro-render-style.md).

## За 3 шага

1. **Включить.** Settings > Rendering > **Retro / PS1** > *PS1 preset* (или применить look *PS1* в разделе *Look*). В файле сцены это `environment: (retro: Some(( .. )))`; `None` (по умолчанию) значит выключено.
2. **Дать сцене туман.** Дальность прорисовки (в пресете 60 м) прячет появление объектов туманом; задайте туману и фону один цвет. Тёмные тесные комнаты читаются как PS1 лучше всего.
3. **Проверить материалы.** Материалы с *Retro* = *Follow scene* тоже ретро. *On* оставляет материал ретро в сцене с выключенным стилем, *Off* оставляет UI или воду чистыми. В библиотечном паке `retro-ps1` есть восемь готовых материалов и демо-сцена.

В коде: `settings.retro = RetroSettings::ps1();` и `Material { retro: Some(true), .. }`.

## Что делает каждая ручка

| Ручка | Действие |
|---|---|
| `snap_resolution` (320x240) | после проекции вершины привязываются к пиксельной сетке этого виртуального экрана: дрожание; работает при любом реальном разрешении. 0 = выкл |
| `snap_grid_m` (0) | дополнительно привязывает мировые позиции к сетке в метрах. Двигает целые объекты шагами: только для крупной геометрии уровня |
| `affine_strength` (1) | 0 = обычные текстуры, 1 = аффинное наложение PS1: текстуры скользят на больших полигонах под углом |
| `affine_fade_near` (4 м) | ближе этого эффект гаснет, ближние поверхности не рвутся |
| `color_bits` (5) | бит на канал, 5 = 15-битный цвет PS1; 0 или 8 = полный цвет |
| `dither_strength` (1) | упорядоченный дизеринг 4x4 в шагах квантования; 0 = полосы |
| `vertex_lighting` (вкл) | свет считается по вершинам (Гуро), только диффузный: центр света на большом полигоне тёмный |
| `shadows` (выкл) | тень солнца из карты по пикселям в режиме освещения по вершинам (блочная, если грубая) |
| `draw_distance` (60 м) | глубже ничего не рисуется; туман подгоняется так, чтобы закончиться там. 0 = выкл |
| `dissolve` (выкл) | растворить последнюю десятую перед обрезкой |
| `cull_small_px` (1) | объекты меньше этого числа пикселей виртуального экрана пропускаются |
| `force_nearest` (вкл) | ретро-материалы берут nearest без мипов, переимпорт не нужен |
| `internal_resolution` (320x240) / `pixel_scale` | сцена рисуется в таком размере и растягивается nearest-фильтром; `pixel_scale` = окно / N. `letterbox` сохраняет внутренний аспект с чёрными полосами, иначе внутренняя высота и аспект окна |

Держите `snap_resolution` равным `internal_resolution`. Стартовые значения, подобранные на прошлом PS1-проекте: затухание аффинности 4 м, привязка вершин на виртуальном экране.

## Ограничения

- Большие полигоны при аффинном наложении сильно искажаются, как на настоящей консоли. Собирайте геометрию уровня из мелких кусков (демо-пак использует кубы по 2 м).
- Освещение по вершинам игнорирует карты нормалей, спекуляр и отражения неба; металл считается диэлектриком. Тени point и spot к нему не применяются.
- Triplanar-материалы берут мировую позицию, поэтому аффинность их не трогает.
- Поверхностные шейдеры получают аффинные `in.uv`, но вершины менять не могут.
- Отсечения по треугольникам нет (нет геометрических шейдеров и compute-отсекателя): пропускаются только объекты целиком.
- Дальность прорисовки и туман выглядят лучше всего, когда цвет тумана равен фону.

## Compat или Full

| | Compat (GL, WebGL2) | Full (Vulkan, Metal, DX12) |
|---|---|---|
| Привязка вершин, аффинность, свет по вершинам, дальность, nearest | да | да |
| Глубина цвета и дизеринг | в mesh-шейдере, по материалам | один раз на итоговой картинке в пост-цепочке (все материалы), без FXAA |
| Низкое внутреннее разрешение | нет, игнорируется | только окно игры |
| Вьюпорт редактора | всё, кроме низкого разрешения | всё, кроме низкого разрешения |
| Частицы и спрайты | не квантуются | квантуются вместе со всем |

Вьюпорт редактора — один проход egui с MSAA, поэтому в меньшем разрешении он рисовать не может; окно игры может.
