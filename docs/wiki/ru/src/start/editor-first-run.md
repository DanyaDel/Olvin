# Первый запуск редактора

Редактор собирается хабом из исходников движка и открывает папку проекта. Интерфейс на английском (STYLE.md, раздел 10), поэтому названия в этой вики даны как в интерфейсе.

## Запуск

```sh
olvin-hub editor install       # один раз: несколько минут сборки
cd my_game && olvin-hub editor open
```

В графическом хабе: страница Editor → Install, затем Open у проекта. Для разработки самого редактора: `cargo run -p editor_dev -- <папка проекта>` (все элементы сразу).

## Что на экране

![Редактор](../images/editor-dark.png)

Рабочая область **Layout** по умолчанию:

| Панель | Где | Для чего |
|---|---|---|
| Scene (вьюпорт) | центр | вид на сцену, гизмо, выбор |
| Game | вкладка рядом | вид из первой камеры сцены; в Play живая игра |
| Hierarchy | слева | дерево объектов |
| Inspector | справа | компоненты выбранного объекта |
| Assets | снизу | папка `assets/` проекта |

Сверху: меню **File / Edit / GameObject / Window**, вкладки рабочих областей, по центру кнопки ▶ ⏸ ⏭ (Play, Pause, шаг кадра), справа ⚙ (Settings). Снизу строка состояния: `● PLAYING` или `PAUSED`, последнее сообщение лога.

## Первые шаги

1. **GameObject → 3D Object → Cube**: создан куб со своим коллайдером.
2. Выделить его в Hierarchy, подвигать `W` (Move) и стрелками гизмо.
3. `Ctrl+S`: редактор спросит путь, по умолчанию `scenes/main.scene.ron`. Игра из шаблона хаба загружает именно её.
4. `olvin-hub run` в папке проекта покажет сцену в игре.

Правки сохраняются явно, Undo/Redo работает на уровне снимков: `Ctrl+Z`, `Ctrl+Shift+Z` (или `Ctrl+Y`). Закрыть с несохранёнными изменениями редактор не даст без вопроса.

## Файлы редактора

| Файл | Что |
|---|---|
| `<config>/olvin-editor/preferences.ron` | тема, камера, масштаб UI, вид по умолчанию |
| `<config>/olvin-editor/layout.ron` | вкладки и раскладка рабочих областей, пишется при выходе |
| `<проект>/logs/editor.log` | лог редактора |

Сбросить раскладку: **Window → Reset Layout**.
