# Что такое Olvin

Olvin: модульный игровой движок на Rust (edition 2024) с хабом проектов и редактором сцен. Каждая подсистема живёт в своём крейте и подключается как плагин.

## Принципы

- **Модульность на уровне подсистем.** Плагин регистрирует системы, система за один вызов проходит по всем данным. Нет виртуальных вызовов на каждый объект, ненужное не компилируется.
- **Плоские массивы в горячих путях.** Рендер раскладывает инстансы по мешам и делает один instanced draw на меш; в установившемся режиме кадр ничего не аллоцирует.
- **Ядро не знает про GPU и окно.** Рендер и платформа связаны через `SurfaceTarget` (raw-window-handle).
- **Минимальный уровень железа: WebGL2 / GLES 3.0.** Всё, что сильнее, включается тиром `Full`, см. [Рендер](../engine/rendering.md).

## Из чего состоит

| Часть | Что делает | Где |
|---|---|---|
| Движок | `olvin_core` (App, Plugin, Resources, Schedule), ECS на `hecs`, окно на winit, рендер на wgpu, физика Rapier, звук kira, ввод, скрипты Rust и Lua, игровой UI | `crates/` |
| Фасад `olvin` | реэкспорты, `DefaultPlugins`, `prelude`; подсистемы включаются фичами | [Фичи olvin](../reference/olvin-features.md) |
| Хаб | создаёт проекты, ставит модули, собирает игру | [Хаб](hub.md) |
| Редактор | сцена, иерархия, инспектор, ассеты, анимация, CSG, моделирование, UV, IDE | [Редактор](../editor/overview.md) |

## Что умеет сейчас

- Сцены `*.scene.ron` с версиями и миграциями, префабы `*.prefab.ron`, материалы `*.mat.ron`, glTF с анимацией.
- PBR (GGX), каскадные тени, тени от spot и point, прозрачность, туман, небо, bloom/GTAO/FXAA/LUT на тире Full, тир Compat для слабых GPU.
- Физика Rapier: тела, коллайдеры, триггеры, контроллер персонажа, raycast.
- Звук с шинами, 3D, реверб, occlusion; ввод с картами действий и переназначением; игровой UI с настоящим текстом.
- Скрипты на Rust (`Behaviour`) и на Lua 5.4 с горячей перезагрузкой и песочницей.
- Сохранения игры (слоты), состояния игры, фоновая загрузка сцен.
- Сборка игры одной командой: `olvin-hub build --release`.
