# Горячая перезагрузка не работает

В Olvin горячо перезагружаются данные, а не код игры.

| Что | Работает | Как |
|---|---|---|
| Lua-скрипты | да | `LuaPlugin { hot_reload: true, .. }` (в шаблоне и срезе только в debug: `cfg!(debug_assertions)`); `LuaScripts::poll` |
| Материалы, текстуры, шейдеры, небо | да | `RenderAssets` проверяет mtime раз в 0,5 с; `AssetManager::with_hot_reload()` |
| Префабы в редакторе | да | раз в 0,4 с |
| Код Rust | нет | пересобрать, см. [#70](https://github.com/DanyaDel/Olvin/issues/70) |
| Сцена в запущенной игре | нет | перезапуск |

## Lua не обновляется

- Игра собрана `--release`, а `hot_reload: cfg!(debug_assertions)`: включите явно.
- Файл не в `dir` плагина (`assets/scripts`) или `dir` относительный от рабочей папки: передавайте `paths.asset("scripts")`.
- Ошибка синтаксиса: оставляется последняя рабочая версия, ошибка в логе.
- Колбэк упал: скрипт отключён до перезагрузки файла; сохраните файл ещё раз.
- Lua перечитывается опросом (`LuaScripts::poll`, по времени изменения файла), а ассеты через `AssetWatcher` (notify): на сетевой папке и в некоторых контейнерах события файловой системы не приходят, перезагрузка ассетов не сработает.

После перезагрузки `self` сохраняется, `start` не вызывается повторно. Новые поля `params` в уже созданных объектах не появятся до перезапуска.

## Редактор

Редактор Lua не загружает, поэтому перезагружать нечего: скрипты проверяйте в игре.
