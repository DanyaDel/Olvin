# Нет звука

## Проверьте по порядку

1. **Модуль и устройство.** Нужен модуль `audio` (`olvin-hub add audio`). Без звукового устройства все вызовы тихо ничего не делают, а движок раз в 2 с ищет устройство снова: звук появится сам, как только оно будет (так же после перезапуска PipeWire). В `DefaultPlugins { audio: AudioPlugin { enabled: true, .. } }` звук включён по умолчанию, в `HeadlessPlugins` выключен.
2. **Путь.** Файлы ищутся в `assets/` (`ProjectPaths::assets`). Путь в коде и в Lua относительно него: `"sfx/door.wav"`, без `..` и абсолютных путей (Lua откажет с ошибкой).
3. **Лог.** Ошибки декодера и нехватки файла идут в лог. Зацикленные звуки, чей файл не загрузился, забываются.
4. **Слушатель.** 3D-звук слышен от `AudioListener` (у камеры в сцене создаётся вместе с ней). Без слушателя панорама и затухание некорректны.
5. **Расстояние.** За `max_distance` громкость падает до нуля; у `AudioSource` по умолчанию 50 м.
6. **Пауза.** На паузе встают шины, кроме `music`.
7. **Голоса.** Лимит 64 голоса и 8 потоков: менее приоритетные виртуализируются.
8. **PipeWire/ALSA.** На Arch `alsa-lib` нужна для сборки, а звук идёт через `pipewire-alsa` или `pipewire-pulse`; проверьте `speaker-test`.

## Проверка в срезе

`cargo run -p vertical_slice --release` должен играть музыку и гул маяка; `--no-audio` отключает устройство.
