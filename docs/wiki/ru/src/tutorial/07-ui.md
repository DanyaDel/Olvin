# Шаг 7. Текст на экране

Сообщение «Дверь открыта» из `plate.lua` ([шаг 5](05-door.md)) покажем на экране. Для этого нужен игровой UI `olvin_gui` (фича `gui` фасада, добавленная в [шаге 1](01-project.md)): отдельный от egui, с настоящим текстом (встроенный Inter с кириллицей).

Скрипт шлёт сообщение командой `ctx:send("hud", text)`. Игра читает очередь `Events<ScriptMessage>` и показывает панель на четыре секунды. Это упрощённая версия `apps/vertical_slice/src/hud.rs`:

```rust
use olvin::core::{EventCursor, Events};
use olvin::gui::{Color, Gui, Node, NodeId};
use olvin::prelude::*;
use olvin::script::ScriptMessage;

struct Toast {
    panel: NodeId,
    text: NodeId,
    cursor: EventCursor,
    left: f32,
}

/// Stage::Startup: строим дерево один раз.
fn build_hud(res: &mut Resources) {
    let (panel, text) = {
        let mut gui = res.fetch_mut::<Gui>();
        let ui = &mut gui.ui;
        let root = ui.root();
        let panel = ui.add(
            root,
            Node::panel()
                .padding(12.0)
                .background(Color::rgba(0.05, 0.06, 0.08, 0.78))
                .anchor(Vec2::new(0.5, 0.0), Vec2::new(0.5, 0.0), Vec2::new(0.0, 24.0))
                .hidden(),
        );
        let text = ui.add(panel, Node::label("").text_size(20.0));
        (panel, text)
    };
    res.insert(Toast { panel, text, cursor: EventCursor::default(), left: 0.0 });
}

/// Stage::Update: сообщения скриптов -> панель, таймер скрытия.
fn update_hud(res: &mut Resources) {
    let dt = res.fetch::<Time>().unscaled_delta();
    let mut shown = None;
    {
        let events = res.fetch::<Events<ScriptMessage>>();
        let mut toast = res.fetch_mut::<Toast>();
        for m in events.read(&mut toast.cursor) {
            if m.name == "hud" {
                shown = m.value.as_str().map(str::to_owned);
            }
        }
        toast.left = if shown.is_some() { 4.0 } else { (toast.left - dt).max(0.0) };
    }
    let toast = res.fetch::<Toast>();
    let mut gui = res.fetch_mut::<Gui>();
    if let Some(t) = &shown {
        gui.ui.set_text(toast.text, t);
    }
    gui.ui.set_visible(toast.panel, toast.left > 0.0);
}
```

Подключите в `main.rs`: `.add_system(Stage::Startup, build_hud).add_system(Stage::Update, update_hud)`.

Как это устроено:

- `Gui { ui, .. }` — ресурс с деревом узлов. `Node::panel()`, `Node::label(..)`, `Node::button(..)`, `row()/column()`, `fill()`, `anchor(..)`, `centered()`.
- `GuiRenderPlugin` (его ставит `DefaultPlugins` с фичами `gui` и `render`) раскладывает дерево и рисует его поверх кадра после постобработки: UI не получает bloom и тонмаппинг.
- Кнопки получают события `UiEvent::Click { name, .. }` в `Events<UiEvent>`; фокус работает с клавиатуры, мыши и геймпада.
- Размеры в UI-пикселях, масштаб экрана учитывается (`Gui::scale`).

В срезе тем же способом сделаны прицел, «Загрузка…» и меню паузы с кнопками «Продолжить» / «Выйти».

> **Статус:** не сделано в `olvin_gui`: перенос строк (только явный `\n`), поля ввода, слайдеры, прокрутка, узел-картинка. Ввод, который обработал интерфейс (клик по кнопке, навигация по фокусу), игре не виден, см. [Игровой UI](../engine/game-ui.md).
