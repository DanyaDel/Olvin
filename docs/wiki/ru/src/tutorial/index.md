# Туториал: первая игра за час

Пошаговый туториал по готовой игре `apps/vertical_slice`: комната с перегородкой, персонаж от первого лица, ящики на физике, нажимная плита, которая открывает дверь, звук, текст на экране, сохранение по `F5`/`F9`. Каждый шаг: что нажать в хабе или редакторе и какой код написать. Весь код и сцены взяты из срезa (`apps/vertical_slice/`), можно подглядывать в оригинал.

## Что нужно

- Установленные Rust, хаб и редактор: [Установка](../start/installation.md).
- Видеокарта с Vulkan или Mesa (см. [установка](../start/installation.md#видеокарта)).
- Звуковые файлы: возьмите `door.wav`, `thud.wav`, `hum.wav`, `theme.wav` из `apps/vertical_slice/assets/` (CC0, их генерирует `apps/vertical_slice/tools/gen_assets.py`).

## Чтобы сверяться

```sh
cargo run -p vertical_slice --release    # готовая игра
cargo test -p vertical_slice             # 7 тестов проходят настоящий уровень без окна
```

> **Статус:** в редакторе Lua-скрипты не запускаются (кнопка Play их не грузит): Lua работает в собранной игре (`olvin-hub run`). Модуля `gui` в каталоге хаба нет, фичу добавляют в `Cargo.toml` руками (шаг 7).
